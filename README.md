### Intraday Stock Return Prediction

An end-to-end machine learning system for predicting short-horizon intraday equity returns from high-frequency market data.

The project includes market-data preprocessing, feature engineering, execution-aware target construction, temporal convolutional networks, multi-horizon prediction, and walk-forward evaluation. A major focus of the work has been designing evaluation methods that distinguish predictive performance from signals that could actually be traded.

**Technologies:** Python · PyTorch · Pandas · NumPy · Time-Series ML · Deep Learning · PySpark

*Source code is private and owned by Drakkar Capital Hedge Fund*

---

### LULD Price Band Reconstruction

A market-data engineering system for reconstructing historical **Limit Up–Limit Down (LULD)** price bands for U.S. equities.

The project translates exchange and regulatory rules into a reproducible data pipeline, handling historical security classifications, opening-price logic, intraday band changes, time bucketing, and large-scale quote and trade data.

**Technologies:** Python · Pandas · PyArrow · Parquet · Market Data

*Source code is private and owned by Drakkar Capital Hedge Fund*
